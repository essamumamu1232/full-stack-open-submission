Overview

This part demonstrates a minimal GraphQL client using Apollo Client to query a public GraphQL API.

Implementation

import { ApolloClient, InMemoryCache, gql } from "@apollo/client";

const client = new ApolloClient({
  uri: "https://countries.trevorblades.com/",
  cache: new InMemoryCache(),
});

client
  .query({
    query: gql`
      query GetCountries {
        countries {
          code
          name
        }
      }`
  })
  .then(result => console.log(result));

Save this code as src/part8/client.js and run with node src/part8/client.js.
