# Full Stack Open – Part 14: Next.js

This directory contains exercises for **Part 14** of Full Stack Open (University of Helsinki), focusing on building applications with Next.js, React Server Components, and modern full-stack patterns.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
